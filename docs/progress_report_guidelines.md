# Weekly progress report guidelines (DATA5500, from the instructor)

Provided by Mo on 2026-10-13. Use this format for every future weekly progress report.

- About one page. Overview of tasks completed this week and tasks planned for next week.
- Must include:
  1. Project name and student's name (Mohamed Mohamed; instructor Weijie Pang)
  2. Tasks completed, with hours spent on each:
     a. Brief description of each task (what was built/implemented, not just planned)
     b. Time spent on each task
     c. Important results or outcomes (e.g., model working, results discovered)
     d. Blockers, challenges, or risks encountered
  3. Plan for next week:
     a. Specific, actionable tasks
     b. Help needed (if any)

## How reports are built here
- Template: Progress Report 2 (reports/DATA5500_ProgressReport2_Mohamed.pdf): header, a task table
  (Task | What was built | Hours | Results), blockers bullets, next-week bullets, help needed.
- Only real, completed work and real numbers (source: outputs/metrics/results.json in the repo).
- Hours are estimates; Mo confirms them before submitting.
- Help needed: Mo does not want questions to the instructor there. Write "None at this time" plus the approach being taken, unless Mo names real help needed.
